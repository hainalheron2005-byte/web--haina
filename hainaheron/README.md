## Project Overview

A comprehensive, interactive, and academically rigorous WebGIS portal for the **Bharathapuzha (Nila) River Basin**, the second longest river basin in Kerala, India.

This portal integrates QGIS-processed spatial datasets covering:
- **River Basin Boundary & Sub-basins** (`WSCODE: 20B4w`, `NRIS: 20-02-04-23`, Total Area: 3,204.66 km²)
- **Drainage Network Hierarchy** (7,280 stream reaches, 5,408.11 km, Strahler Stream Orders 1 to 5)
- **Check Dams & Major Reservoirs** (13 major hydraulic structures with photos and operational attributes)
- **Lithological Formations** (192 units across 11 formations: Charnockite, Migmatite Complex, Peninsular Gneiss, Basic Dykes, and Alluvium)
- **Transportation Corridors** (2,923.24 km of roadways including NH 544, State Highways, and District Roads)
- **Waterbody Spread** (101.30 km² / 10,129.8 Ha of reservoir storage surfaces)

## Technical Architecture

- **Mapping Engine:** Leaflet.js (v1.9.4)
- **Analytics & Data Visualization:** Chart.js (v4.4.1)
- **GIS Preprocessing:** QGIS 3.44.12-Solothurn, GDAL 3.13.1, OSGeo4W Python 3.12
- **Coordinate Reference Systems:** WGS 84 (EPSG:4326) / UTM Zone 43N (EPSG:32643)
- **Styling:** Responsive HTML5/CSS3 with Glassmorphism, CSS Grid & Flexbox
- **Deployment:** GitHub Pages
